How to fill this template

Set the week start, define three outcomes that would make the week a win, plan each day (AM / PM / must-do), track habits, park distractions in notes.

  • Big 3 first: Everything else supports those outcomes.
  • Time-box: Put meetings and deep work in AM/PM slots.
  • Friday review: Capture wins before weekend.

Example Big 3

1) Ship listing photos for 12 units
2) Close 2 viewings
3) Draft landlord proposal
